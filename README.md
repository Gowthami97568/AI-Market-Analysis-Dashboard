# Global AI Market Analysis Dashboard

## 📊 Project Overview
This project analyzes global AI investment trends, employment rates, and automation impact using Power BI.

## 🛠 Tools Used
- Python (Google Colab)
- Power BI

## 📈 Dashboard Features
- KPI Cards (Total Investment, Avg Employment, Avg Automation)
- AI Investment Trend by Year
- Country-wise Investment Comparison
- Scatter Plot (Automation vs Employment)
- Pie Chart (Country Share)
- Interactive Slicer

## 🔍 Key Insights
- AI investment is increasing year by year
- Some countries dominate AI spending
- Automation impact varies across countries

## 📂 Files Included
- AI_Dashboard.pbix → Power BI dashboard
- AI_Market_Analysis.ipynb → Data analysis
- global_ai_workforce_automation_2015_2025.csv → Dataset
